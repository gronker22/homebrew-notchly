# Notchly Homebrew Tap

Install [Notchly](https://github.com/gronker22/Notchly) — the MacBook-notch
Dynamic-Island hub — with one command:

```bash
brew install --cask gronker22/notchly/notchly
```

Universal build (Intel + Apple Silicon), macOS Sonoma (14) or newer. Update with
`brew upgrade --cask notchly`.
